# Appointment Booking System - Frontend

## Design References
- Calendly (clean booking flow)
- Modern SaaS dashboards (Linear, Notion)

## Color Palette
- Primary: #6366f1 (Indigo-500)
- Primary Dark: #4f46e5 (Indigo-600)
- Accent: #8b5cf6 (Violet-500)
- Success: #10b981 (Emerald-500)
- Warning: #f59e0b (Amber-500)
- Danger: #ef4444 (Red-500)
- Background Light: #f9fafb
- Background Dark: #0f172a
- Text: #111827 / #f1f5f9

## Typography
- Sans: Inter, system-ui
- Headings: font-semibold to font-bold
- Body: font-normal

## Key Design Elements
- Glassmorphism cards with backdrop-blur
- Soft shadows (shadow-lg, shadow-xl)
- Rounded corners (rounded-xl, rounded-2xl)
- Smooth hover animations (transition-all duration-300)
- Gradient accents for CTAs
